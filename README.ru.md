# aiomoysklad

Асинхронный набор инструментов для интеграций с JSON API 1.2 [МоегоСклада](https://www.moysklad.ru).
English version: [README.md](README.md).

**Статус: проектирование.** Рабочего кода пока нет. План версии 0.1 описан в
[docs/design.md](docs/design.md) (на английском). На живом аккаунте МоегоСклада ничего
не проверялось.

В 0.1 войдёт то, что чаще всего нужно интегратору и чего нет в существующих клиентах на
Python: лимитер, который считает вес запросов так же, как МойСклад, не больше 5 запросов
одновременно, повтор после 429 по заголовкам `X-Lognex-*`, защита от автоматического
отключения доступа к API, листание, конструктор параметра `filter=`, краткие отчёты об
остатках, ассортимент без остатков, заказы покупателей и вебхуки.
